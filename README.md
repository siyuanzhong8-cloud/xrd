# XRD 文献识图交接说明

时间一律为 **Asia/Seoul (UTC+9)**。本包打包于 2026-11-25 17:10 左右。

请先读这一份，再看 `xrd_qwen/使用说明.md`（安装、密钥、命令）和 `核验与进度/核验说明.md`（怎么对照原图逐项检查）。

**有仪器导出的 `.xy` / `.txt` / `.csv` 时，请一定优先读数据。** 从数字里寻峰，比看图片估读要准得多。本工具读图，主要是补图例、hkl、卡片竖线和文字信息。

**API Key 只从环境变量 `DASHSCOPE_API_KEY` 读取。** 不要写进代码、配置文件、日志或聊天。本压缩包里没有密钥。

## 1. 我们在做什么

从文献 PDF 里自动找出 XRD 图，把曲线描成 `.xy` 数字，再做物相判断；加上 `--fit` 时，再用 DARA / BGMN 做结构拟合。希望无拟合时单篇大约 60 秒以内。

四步流水线：

1. **找图并裁切**（`pdf_xrd.py` + 视觉模型）。默认定位模型是 `deepseek-v4.1-flash-1017`（思考关闭）。需要更稳的双模型择优时加 `--locate-model auto`。
2. **读坐标轴、描曲线**（`calib_read.py`、`digitize_crop.py`、`trace_xrd.py`）。这一步主要是代码，不是模型。当前版本会先按图例颜色分通道描线，再合并；并尽量避开网格、文字和卡片竖线。
3. **物相 / 路线判断**（`xrd_vl.py`）。默认 `qwen3.5-omni-flash`，失败或超时则改 `qwen3.8-flash`，若 403 再改 `qwen3.6-flash`。必须带上图注或上下文；没有图注时物相结果基本不可用。
4. **可选拟合**（`phase_fit.py`，`--fit`）。需要单独的 `dara-venv`，用环境变量 `XRD_DARA_PYTHON` 指向它的 Python。已发表的 Rietveld 精修图应当跳过。描出来的曲线没有真实计数统计，Rwp / GOF 只能相对比较，不能当论文里的精修指标用。CIF 缓存在 `cod_cache/`（本包未附带缓存）。

接口是阿里云百炼的 OpenAI 兼容地址：`https://dashscope.aliyuncs.com/compatible-mode/v1`。

## 3. 已经修好、以及还没过关的地方

当前代码（`xrd_qwen/trace_xrd.py` 等）里已经包含：

- 按颜色分通道描线（用户建议的路子）
- 轴标签重定标：框内 10–70 的刻度可延伸到脊上印出的 80°；只拒绝明显缩没的范围
- 保留孤立的彩色峰茎、与黑色曲线相接的彩色段；跳过悬空的字母横档
- 左边缘单峰不要被「卡片竖线」过滤器误删（唇膏 7.26° 就是这样收回来的）
- v11 起的刻度约束：残差变差就不要硬吸附；略出框的端点不要硬收到脊上；不要把右边的放大插图吞进主图坐标

- **LDH Fig 9b** 实验谱低角峰：11.34°（v12 偏到约 9.9°）。模拟谱仍是独立的一条，没有塌到实验谱上；模拟主峰随轴校正移到约 38.3°
- **唇膏图 ~7.26°** 氯泥石峰：强度约 57.5（v11/v12 都是 0）；9.9 / 10.8 / 11.2 / 12.5 附近的卡片竖线为 0；石英 31.04° 仍在

还没过关、建议优先接着修的：

1. **唇膏赤铁矿 104 峰。** v13 里 7.26° 回来了，但 104 的尖顶比官方 v12 弱：最高点跑到 38.42°，38.70° 附近强度约 159（v12 是 38.70° / 272）。若这一处能在不引回卡片竖线、也不丢掉 7.26° 的前提下修回去，这张图就有希望改成整图正确（18 张里会到 6 张）。
2. **多曲线仍不稳。** HEA、LSCO 等堆叠图还是偏「方框」；TiO₂ 的 P25 已有真实峰（约 25.3°），但曲线中段仍可能有空洞。
3. **materials 那篇 400 °C 曲线。** 官方 v12 第一遍无拟合目录里曾被一块过大的「标签框」丢掉，后来的防护能找回，但要以新跑的结果为准。
4. **用当前代码做一轮完整的 13 篇官方重测**（先无拟合，再按需 `--fit`），把 v13 的 5/18 放到与 v11/v12 相同的流程下核一次。
5. 卡片竖线、轴标定在复杂排版上仍脆弱。有原始 `.xy` 时不要用读图结果当金标准。

有一份外部补丁（基于更早的 v10 脚本，只在合成图上过了单元测试）修过部分定标，但也引入过新的退化（插图被吞进主轴、峰位整体平移等），**不要整份替换当前的 `trace_xrd.py`**。可以参考其中「按颜色跟踪、拒绝明显坏标定、不要为了清边把稀疏峰裁掉」的想法，但必须在这 13 篇图上回归。

## 4. 环境与运行

需要 Python 3.10+（3.9 一般也能用）。Windows 用 PowerShell。

```powershell
cd <解压后的 xrd_qwen 目录>
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt

# 只在当前窗口临时设置密钥（不要把完整密钥发给别人或写进脚本）
$env:DASHSCOPE_API_KEY = "sk-你的密钥"

# 不花接口费的检查
python xrd_vl.py .\examples --dry-run
python pdf_xrd.py .\examples\papers --dry-run

# 从文献 PDF 跑完整流程（定位、裁图、描点、识图）
python pdf_xrd.py .\examples\papers --out-dir .\results_pdf_test

# 如需拟合，先按使用说明第 4.1 节单独建 dara-venv，再：
# $env:XRD_DARA_PYTHON = "<dara-venv 的 python 路径>"
# python pdf_xrd.py .\某篇.pdf --out-dir .\results_fit --fit
```

Linux 同样只从 `DASHSCOPE_API_KEY` 读取密钥。测试文献在本包的 `测试文献/`，清单与 DOI 见 `核验与进度/papers_manifest.json`。`examples/papers/` 里已有两篇示例 PDF（钴纳米棒、materials-15-07378）。

默认定位模型：`deepseek-v4.1-flash-1017`。物相默认 `qwen3.5-omni-flash`，失败回退见第 1 节。本账号下 `qwen3-vl-flash`、`qwen-vl-plus`、`qwen-vl-max` 会 404，不要写回默认值。

## 5. 怎样才算一张图「整图正确」

必须同时满足，且**不要以流水线自己的 pass 为金标准**，要对照原图刻度和论文给出的 2θ：

- 找到并正确裁切（不要把旁边的放大插图吞进主图，也不要只裁到一半）
- 主峰相对原图刻度 / 论文已给 2θ 大约在 **0.3° 以内**
- 主要实验曲线不是全零
- 没有把标准卡片竖线描成主峰
- 物相与论文一致（多报不被支持的相当作部分正确，不能算整图正确）
- 中子衍射的 d 值图等非 2θ 图应当剔除，不能当 XRD 2θ 来描

建议先打开 `核验与进度/校验图/` 里的对比图，再对照 `summary_v11.md`、`summary_v12.md`、`summary_v13.md`。

## 7. 建议接手后的顺序

1. 安装依赖，用 `examples/` 做 `--dry-run`，再跑两篇示例 PDF，确认能出裁图、`.xy` 和报告。
2. 用当前代码在新目录重跑 13 篇（先不要 `--fit`），按第 5 节逐图核对，更新对照表。
3. 优先修唇膏 104 尖顶，同时保住 7.26°、MoS₂、ZIF、LDH Fig 4 / Fig 9b、BSM20、钴的 6 条曲线、TiO₂ 的 P25、LFP 的 2a/2b 分框。
4. 再处理多曲线方形描线、中段空洞，以及仍不稳的轴标定。
5. 需要拟合时再跑 `--fit`。跳过已发表的 Rietveld 图；缺 CIF 或超过时限就如实记录，不要硬凑。

有问题请对照原图，而不是只看叠加图是否「好看」。
