# XRD 识图工具使用说明

用阿里云百炼的通义千问视觉模型，批量识读 XRD 图谱：版式、峰位、物相判断和合成/复合路线建议。结果保存为 JSON、Excel 可打开的 CSV，以及一份 Markdown 汇总报告。

**有仪器导出的 `.xy` / `.txt` / `.csv` 原始谱图数据时，请一定配合使用。** 从数字里寻峰，比让模型“看图估读”峰位要准得多。模型读图适合补图例、hkl 标注、标准卡片竖线和文字信息；峰位和相对强度应优先采信 `xy_peaks.py` 的结果。

本工具面向化学 / 材料研究。需要本机已安装 **Python 3.10 或更高版本**（3.9 一般也能用，推荐 3.10+）。在 Windows 上用 PowerShell 操作即可。

## 1. 在阿里云百炼申请 API Key

1. 用阿里云账号打开百炼控制台：<https://bailian.console.aliyun.com/>
2. 按提示开通「大模型服务平台百炼」（未开通时控制台会引导你开通）。
3. 进入 **API-KEY** 管理页（也可直接打开 <https://bailian.console.aliyun.com/?apiKey=1#/api-key>），单击创建密钥并复制。密钥通常只完整显示一次，请自行妥善保存，不要发给别人，也不要写进代码或发到聊天里。
4. 更完整的官方说明：<https://help.aliyun.com/zh/model-studio/get-api-key>

中国站默认使用接口地址：

`https://dashscope.aliyuncs.com/compatible-mode/v1`

本工具已写好该地址，一般不用改。若你的账号在国际站或其它地域，模型列表和域名可能不同，请以控制台为准。

## 2. 用 PowerShell 设置环境变量

本工具**只**从环境变量 `DASHSCOPE_API_KEY` 读取密钥，不会在代码里写死，也不会在日志里打印密钥。

**当前窗口临时生效**（关掉窗口即失效）：

```powershell
$env:DASHSCOPE_API_KEY = "sk-你的密钥"
```

**写入用户环境，永久有效**（注意：`setx` 成功后，**必须关闭当前 PowerShell，再新开一个窗口**，新窗口才能读到该变量）：

```powershell
setx DASHSCOPE_API_KEY "sk-你的密钥"
```

新开窗口后可用下面命令确认变量已存在（不要把完整密钥发到聊天或截图给别人）：

```powershell
if ($env:DASHSCOPE_API_KEY) { "已设置，长度 $($env:DASHSCOPE_API_KEY.Length)" } else { "尚未读到，若刚用过 setx，请先关掉并重开终端" }
```

## 3. 安装

在 PowerShell 中进入本文件夹（请改成你解压后的实际路径）：

```powershell
cd D:\xrd_qwen
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
```

若执行 `Activate.ps1` 时提示“无法加载，因为在此系统上禁止运行脚本”，可先对当前用户放开本地脚本策略，再重新激活：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
.\.venv\Scripts\Activate.ps1
```

没有虚拟环境、直接安装到当前 Python 也可以：`pip install -r requirements.txt`。

## 4. 常用命令示例

先不花接口费，检查图片能否编码、提示词能否构造（**不需要 API Key**）：

```powershell
python xrd_vl.py .\examples --dry-run
```

只从原始数据寻峰（不调用模型，推荐先跑这一步）：

```powershell
python xy_peaks.py .\examples\TiO2_anatase.xy --plot
```

上面会生成 `TiO2_anatase_peaks.csv` 和 `TiO2_anatase_peaks.png`。可以调整阈值：

```powershell
python xy_peaks.py .\examples\TiO2_anatase.xy --prominence 0.02 --height 0.03 --distance 0.3 --plot
```

批量识图，并把同名 `.xy` 峰表一起送给模型：

```powershell
python xrd_vl.py .\examples --data .\examples --context "合成锐钛矿 TiO2 与 ZnO 对照样，辐射源 Cu Kα"
```

只处理一张图、换一个模型、只做其中几项任务：

```powershell
python xrd_vl.py .\examples\TiO2_anatase.png --data .\examples\TiO2_anatase.xy --model qwen3.5-omni-flash --tasks layout,peaks,phase
```

已处理过的图片默认会跳过。若要强制重跑：

```powershell
python xrd_vl.py .\examples --data .\examples --overwrite
```

其它常用参数：

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `--model` | 百炼模型名 | `qwen3.5-omni-flash` |
| `--tasks` | `layout,peaks,phase,synthesis` 或其子集，也可用中文：版式,读图,物相,合成 | 全部 |
| `--context` | 样品背景（前驱体、元素、合成方法、辐射源等） | 无 |
| `--data` | 原始谱图文件，或存放同名数据的文件夹 | 无 |
| `--workers` | 并发数 | 4 |
| `--out-dir` | 输出目录 | `results` |
| `--max-side` | 图片长边超过该像素则等比缩小再上传 | 2048 |
| `--max-retries` | 失败重试次数（含 429 限流的指数退避） | 5 |
| `--overwrite` | 覆盖已有结果 | 关闭 |
| `--thinking` | 开启模型思考模式（默认关闭 `enable_thinking=False`，更快更省） | 关闭 |
| `--dry-run` | 只检查编码和提示词，不调用接口 | 关闭 |

任务说明：

- **layout / 版式**：单图还是多子图、坐标轴范围与标签、曲线数量、图例、是否有 PDF/JCPDS 标准卡片竖线。
- **peaks / 读图**：每条曲线的主要峰 2θ、相对强度、hkl（图上没有就标 `null`）和置信度。
- **phase / 物相**：可能物相及依据，并写明不确定性。
- **synthesis / 合成**：可能的合成或复合路线，并写明不确定性，仅供参考。

## 4.1 从文献 PDF 自动找图、数字化并识图

`pdf_xrd.py` 把一篇（或一个文件夹里的）PDF 做成「找出 XRD 图 → 裁出来 → 读刻度并描成 .xy → 寻峰 → 物相/路线判断」。不依赖 Windows OCR，Linux 和 Windows 都能跑。需要已安装 PyMuPDF（`pip install -r requirements.txt` 会装上）。

```powershell
# 先不花钱，只看哪些页会被当成候选
python pdf_xrd.py .\examples\papers --dry-run

# 完整流程（定位、裁图、读刻度、描线、叠加复核、识图）
python pdf_xrd.py .\examples\papers --context "如有需要可写辐射源或样品信息"

# 只跑某一页、换模型
python pdf_xrd.py .\examples\papers\materials-15-07378.pdf --pages 5 --phase-model qwen3.8-flash
```

流程简述：

1. **找图与裁剪。** 先用图注/正文关键词（XRD、X-ray diffraction、2θ、diffraction pattern 等）筛候选页。若全文已有图注命中，则只把这些图注页送给视觉模型，正文里仅仅提到 XRD 的页默认跳过（可用 `--all-keyword-pages` 恢复旧行为）。没有文本层的「打印成 PDF」仍走原来的回退：含嵌入图的页会送检。定位默认 `deepseek-v4.1-flash-1017`（思考关闭）：在三篇测试论文上图号与框质量总体不弱于原来的 `auto`（DeepSeek 与 `qwen3.6-flash` 并行择优），且不必跑两个模型。个别裁框可能略带邻图；需要更稳的双模型择优时加 `--locate-model auto`。整页图缩小到长边约 1280 并以 JPEG 上传；裁图仍按 `--dpi`（默认 200）从 PDF 高分辨率渲染。所有候选页同时发出定位请求（不受 `--workers 4` 限制），单次超时约 25 秒并重试一次；若超过约 12 秒仍未返回会再发一趟对冲请求，先到先用（`--no-hedge` 可关）。默认外扩 3%，并再问一次模型做二次校正（`--locate-model auto` 时定标/校正仍走 `qwen3.6-flash`，否则跟随定位模型）。**一幅图裁出后立刻进入数字化与识图，不必等其它页定位结束。** 裁图保存为 `results_pdf/crops/<pdf名>_p<页>_<序号>.png`。
2. **读刻度并数字化，再做物相解释。** 模型在裁图上读出 x 轴范围、曲线/图例和靶材线索，并尽量标出图例色条和文字框；描线前会把这些区域涂白（`--no-mask` 可关）。**精确 2θ 一律由程序描点得到，不以模型目测峰位为准。** 描点（`frame_trace`）会在裁图内找到 XRD 数据框（多子图时优先选刻度整齐的 2θ 框，而不是旁边的极化曲线或柱状图），用底轴刻度短线做线性定标（第一根短线若贴着左脊，常是未标注的次刻度，不会强行钉成模型读出的 x 轴左端，例如 40–90 的 15 根 5° 短线会定为 35–105 而不是 40–110），再按图例颜色把坐标框拆成各条曲线的掩膜、分别描点后合并（相近的绿/蓝用 Lab 距离和较紧的色相窗口分开；压缩模糊造成的混色也会尽量分给最接近的图例色）。描线前会尽量抹掉网格、残余文字和 PDF/JCPDS 卡片竖线，避免把它们描成峰。若某一颜色通道描成方框，或在中段出现整段空洞，会沿该颜色带重新连接，而不是留下矩形或零缺口。写出 `.xy`、重绘图和叠加校验图。`figures_index.json` 会一并保存曲线名与颜色、`plot_box_1000`、坐标范围和涂白框，便于按同一套定标复描。定标时，印刷短线残差较小且落在框内则优先于模型像素（模型读数可自洽但仍整体平移）；略出框的端点不硬收到脊上，以免把 20–90° 的好轴拉歪。选主框时要求预测 2θ 范围覆盖标注范围的大部分，避免主峰附近的窄条或右侧放大图（沸石 10–15° inset）变成主框。堆叠图按模型给出的曲线数拆分，不再在少 1 条时保留短集合（例如丢掉 P25）；也不会在已给出曲线数之外再发明额外的「曲线N」。印刷刻度若还延伸到右框外（例如 30–105° 轴上的 100–105°），会在不跨过低墨间隙、不吞掉旁边放大图的前提下把框扩到这些刻度。描线时会避开几乎填满整条带的方框伪迹，并在左右脊附近抑制轴墨带来的尖峰。导出的 2θ 默认裁在刻度覆盖区间内，避免框外外推。单条未堆叠谱若检测不到实线基线，会改用数据地板，避免把坐标轴当成基线而描成全零；堆叠图最底一条若贴在坐标轴上，也会改到数据地板。连在峰杆上的公式/标记文字（例如 ★ZnₓOTfᵧ(OH)₂ₓ₋ᵧ·nH₂O 的 “nH2O”）会被涂掉宽头、保留峰杆，以免描出假峰。描点完成后，物相解释与叠加复核并行（复核不再挡住识图）。默认任务在 `--tasks all` 时实际只向模型要 `phase`+`synthesis`（精确峰位已由描点给出，可避免过长输出导致超时重试）。复核与定标在 `--locate-model auto` 时用 `qwen3.6-flash`，否则跟随定位模型。物相解释默认用 `qwen3.5-omni-flash`（在三篇测试论文上与 `qwen3.8-flash` 物相结论一致，且更快）；输入是程序描出的峰表加图注。可用 `--phase-model qwen3.8-flash` 或 `qwen3.6-flash` 切回旧模型。若默认的 `qwen3.5-omni-flash` 欠费、失败、报错或输出无法解析，会自动改用 `qwen3.8-flash`（终端会提示，不会打印密钥）。若 `qwen3.8-flash` 返回 403（免费额度用尽，且控制台仍开着「仅使用免费额度」），会再改走 `qwen3.6-flash` 试一次，以便物相不空。物相正文写在 `<裁图名>.png.json` 的 `result.phase`，并写入 `figures_index.json` 的 `phase` 字段。计时包含这次真实识图时间，不以事后补跑为准。`deepseek-v4.1-flash-1017` 支持视觉，适合版式/分类/定位，但官方 `detail=high` / `vl_high_resolution_images` 不会增加其 image token，**不要用来读精确峰位**；思考模式请保持关闭。
3. **DARA 全谱拟合（可选，默认关闭）。** 加 `--fit` 后，按候选物相去 COD 下载 CIF（默认写入工具目录下的全局 `cod_cache/`，可用 `--cif-cache` 或环境变量 `XRD_COD_CACHE`），多图/多曲线并行调用 DARA+BGMN，再让模型解读。会从「金属锌(Zn)」这类中文名里抽出化学式；解析不到可检索化学式时跳过而不是报死。已经是论文里发表的 Rietveld 精修图会自动跳过拟合。默认每图只拟合一条代表性曲线（约 60 秒超时）；需要全部曲线时加 `--fit-all-curves`。拟合使用整段描点 2θ 范围（关闭 DARA 的 `enable_angular_cut`，避免被自动裁到约 50°）；同时把仪器函数的 `.ger` 一并拷进工作目录，否则文献图常见的 80–110° 会超出默认 `*.geq` 表而失败。描点若外推到第一根刻度左侧（例如 2°），写入拟合文件时会裁到不低于 5°。若进程在写出 `report.json` / `fit.png` 之后的收尾阶段超时，仍按已写出的结果保留。需要单独的 `dara-venv`（不要装进本工具的 `.venv`）。详见下面的安装说明和 `phase_fit.py`。

一篇带实验 XRD 图的论文，完整流程（不含拟合）目标是大约一分钟内完成；加 `--fit` 会再增加精修时间（DARA 单次约 60 秒超时，若已写出 `report.json`/`fit.png` 仍保留）。实际墙钟取决于接口排队和页数。精确峰位由程序描点得到，不再依赖模型目测。默认定位模型为 `deepseek-v4.1-flash-1017`（可用 `--locate-model auto` 恢复与 `qwen3.6-flash` 并行择优）；物相解释默认 `qwen3.5-omni-flash`（可用 `--phase-model qwen3.8-flash` 或 `qwen3.6-flash`），输入为描点峰表+图注。若默认的 `qwen3.5-omni-flash` 欠费、失败、报错或无法解析，会自动改用 `qwen3.8-flash`；若 `qwen3.8-flash` 返回 403，会改走 `qwen3.6-flash` 再试一次，避免物相为空。`deepseek-v4.1-flash-1017` 支持视觉，但官方高分辨率开关（`detail=high` / `vl_high_resolution_images`）不增加其 image token；适合版式分类，不适合精确读峰。思考模式请保持关闭。

### DARA 环境安装

不要把 `dara-xrd` 装进本工具的 `.venv`（它依赖很重，且需钉死 `pydantic<2.14`）。另建环境后，可用环境变量 `XRD_DARA_PYTHON` 指向其中的 Python；不设的话，脚本也会自动探测本目录下的 `dara-venv`。

**Linux / macOS：**

```bash
cd /path/to/xrd_qwen
python3 -m venv dara-venv
dara-venv/bin/python -m pip install -U pip
dara-venv/bin/python -m pip install "dara-xrd==1.3.0" "pydantic<2.14"
export XRD_DARA_PYTHON="$PWD/dara-venv/bin/python"
# 可选：预先下载 BGMN（否则第一次拟合时会自动按操作系统下载）
dara-venv/bin/python -c "from dara.bgmn.download_bgmn import download_bgmn; download_bgmn()"
python pdf_xrd.py ./examples/papers --fit
```

**Windows（PowerShell）：**

```powershell
cd C:\path\to\xrd_qwen
python -m venv dara-venv
dara-venv\Scripts\python -m pip install -U pip
dara-venv\Scripts\python -m pip install "dara-xrd==1.3.0" "pydantic<2.14"
setx XRD_DARA_PYTHON "$pwd\dara-venv\Scripts\python.exe"
# 重开终端后再运行
python pdf_xrd.py .\examples\papers --fit
```

说明：

- DARA 会为 Linux / macOS / Windows 分别下载 `bgmnwin_Linux.zip`、`bgmnwin_Darwin.zip`、`bgmnwin_Windows.zip`。Linux 官方二进制（BGMN 4.2.23）可直接运行，一般不需要 Wine。
- 若在较老的集群上出现 `GLIBC_2.29 not found`，请按 [DARA 安装文档](https://cedergrouphub.github.io/dara/install.html) 用 patchelf / 自编译 glibc 处理。
- 较新的 scipy 下，`dara/search/peak_matcher.py` 需要一处标量补丁，否则认相结果可能为空或报 `ZeroDivisionError`。`phase_fit.py` 在探测环境时会自动修补。
- 从文献图数字化得到的曲线没有真实计数统计，Rwp / GOF 只能作相对参考，不能当成仪器数据的精修质量。
- CIF 默认缓存在工具目录的 `cod_cache/`（可用 `XRD_COD_CACHE` 或 `--cif-cache` 更改），不随 `--out-dir` 清空。
- 物相名如「金属锌(Zn)」会自动抽出化学式 Zn；解析失败则跳过该相，不会让整步失败。论文中已经发表的 Rietveld 精修图会自动跳过拟合。

常用参数（在 `xrd_vl.py` 已有参数之外）：

| 参数 | 含义 | 默认 |
| --- | --- | --- |
| `--pages` | 限定页码，如 `5` 或 `4-6,8` | 全部页 |
| `--model` | 未单独指定时的兜底模型 | `qwen3.5-omni-flash` |
| `--locate-model` | 定位模型。默认单独使用 DeepSeek；`auto` 为与 `qwen3.6-flash` 并行择优（此时定标/复核仍用 `qwen3.6-flash`） | `deepseek-v4.1-flash-1017` |
| `--phase-model` | 物相解释模型（描点峰表+图注；精确 2θ 以描点为准）。可选 `qwen3.8-flash` / `qwen3.6-flash`。默认 3.5-omni 若欠费会回退到 3.8；3.8 若 403 再回退到 3.6 | `qwen3.5-omni-flash` |
| `--workers` | 识图/数字化并发数（定位页不受此上限） | 4 |
| `--locate-workers` | 定位并发数，`0` 表示所有候选页同时发出 | 0 |
| `--dpi` | 裁图分辨率（定位页另按长边缩小） | 200 |
| `--locate-max-side` | 定位用整页图的长边像素 | 1280 |
| `--call-timeout` | 单次接口超时（秒），超时后重试一次 | 25 |
| `--hedge-after` / `--no-hedge` | 定位对冲等待秒数；`--no-hedge` 关闭 | 12 |
| `--all-keyword-pages` | 即使已有图注命中，仍把仅正文提及 XRD 的页送检 | 关闭 |
| `--pad` | 裁框外扩比例 | 0.03 |
| `--no-refine` | 关闭裁框二次校正 | 关闭（即默认会校正） |
| `--no-digitize` | 跳过读刻度与描线，只裁图+读图 | 关闭 |
| `--no-review` | 不让模型复核叠加校验图 | 关闭（默认会复核） |
| `--no-mask` | 描线前不遮盖图例/文字框 | 关闭（默认会遮盖） |
| `--fit` | 尝试 DARA 拟合（环境不可用或无 CIF 会跳过） | 关闭 |
| `--fit-all-curves` | 加 `--fit` 时拟合一幅图里的全部曲线（默认每图一条代表性曲线，多图并行；单次拟合超时约 60 秒） | 关闭 |
| `--cif-cache` | CIF 缓存目录 | 工具目录下 `cod_cache/` |
| `--out-dir` | 输出目录 | `results_pdf` |

输出（默认在 `results_pdf/`）：

| 路径 | 内容 |
| --- | --- |
| `crops/` | 裁出的 XRD 图 |
| `xy/` | 数字化后的 `.xy`（按图例命名） |
| `digitize/<裁图名>/replot.png` | 按 2θ 重绘的谱图 |
| `digitize/<裁图名>/overlay_check.png` 或 `validate.png` | 原图与提取曲线的叠加校验 |
| `summary.csv`、`peaks.csv`、`report.md` | 与批量识图相同，并含页码、图注、裁图/重绘/校验图路径 |
| `fits/<曲线名>/fit.png`、`report.json` | 加 `--fit` 后的观测/计算拟合图和精修报告（含相含量、Rwp、GOF） |
| `cod_cache/`（工具根目录，不在 zip 里） | 全局 CIF 缓存，换输出目录不必重复下载 |
| `figures_index.json`、`detect/`、`overlays/` | 定位框和索引，便于核对 |

示例 PDF 在 `examples/papers/`（两篇公开论文）。描线结果必须人工看叠加校验图；数字化峰位也不是仪器原始数据，精度受裁框、刻度读数和描线质量限制，但通常比纯看图估峰更准。有 `.xy` 原始数据时仍然应当优先用原始数据。

## 7. 费用与注意事项

- **会消耗百炼额度 / 费用。** 大批量跑之前，建议先用 `--dry-run` 确认文件无误，再小范围真跑一张看看效果。并发默认 4，遇到 429 限流会自动退避重试；若仍频繁限流，请把 `--workers` 调小。
- **模型读峰精度有限，必须人工核对。** 从图片估读的 2θ、强度、hkl 都可能有偏差，不能直接当精修或卡片检索的输入。物相判断和合成路线是带不确定性的建议，不能代替实验方案、文献调研和安全评估。
- **有原始数据时，读数据比读图准。** 把 `.xy`（或两列 2θ、强度的 `.txt` / `.csv`）与同名图片放在一起，加上 `--data`。`xy_peaks.py` 用 `scipy.signal.find_peaks` 给出峰位、相对强度和 FWHM 估算，主脚本会把这张峰表随图一起发给模型。
- 支持的图片格式：png、jpg、jpeg、bmp、tif、tiff、webp。TIFF 会先转成 PNG；长边超过 2048 像素会先等比缩小再上传（可用 `--max-side` 修改）。
- **数字化以程序描点和刻度短线为准。** 同一裁图里 2θ 范围不同的放大图 / inset 会被屏蔽；定标吸附到印刷刻度短线，并覆盖坐标轴两端（第一根标注刻度左侧的峰也会保留）。若 VLM 把刻度点在峰上而不是印刷数字上，会用轴下标签重定标（要求新刻度覆盖原标注范围的约 85% 以上，避免把 10–90° 轴缩成短子集）。描完后会用原图主峰与刻度位置做自检：若定标已经钉在短线上且残差很小，约 0.5° 的峰顶抖动不会改轴；大约 1.2° 以上的系统偏差才会按刻度短线重定标。标准卡片或成排的物相标记竖线会被尽量抹掉，但孤立的彩色峰芯（例如点在峰上的品红标注）会保留。多色/堆叠图会先按颜色分通道描线再合并；单条黑色实验谱会把紧贴黑线的彩色峰芯并入墨迹再描。若某条 `.xy` 强度全为零，叠加复核必须为 **fail**，不要写成 pass。
- **只处理实验室 2θ XRD。** 中子衍射，或横坐标为晶面间距 d、散射矢量 Q、飞行时间 TOF 的图，会在定标阶段判定为非 2θ 并跳过描线和识图。
- **物相候选必须有峰位或图上标注作为证据。** 图注里的原料、掺杂剂或弥散相，若峰表和图上对不上，不应写入物相列表。
- API Key 泄露风险高，请只用环境变量，不要写进脚本、不要提交到 Git、不要发到聊天记录。

## 8. 把本工具拷到 Windows 电脑

推荐直接解压项目旁边的 `xrd_qwen.zip`（若你是从共享云电脑下载，文件一般在 `/workspace/xrd_qwen.zip`）。解压后的文件夹结构应类似：

```
xrd_qwen\
  pdf_xrd.py             从文献 PDF 找图、数字化并识图
  xrd_vl.py              批量识图（也可单独用于已有图片）
  xy_peaks.py            从原始数据或数字化 .xy 寻峰
  calib_read.py / digitize_crop.py / phase_fit.py
  # dara-venv 需本机另建，不要放进发布用的 zip
  generate_examples.py   如需重新生成示例图可运行
  requirements.txt
  使用说明.md
  README.md
  examples\
    papers\             两篇公开论文，供 PDF 流程测试
    TiO2_anatase.png
    ...
```

然后：

1. 安装 [Python 3.10 或更高版本](https://www.python.org/downloads/windows/)，安装时勾选 **Add python.exe to PATH**。
2. 用资源管理器进入解压目录，在地址栏输入 `powershell` 回车。
3. 按第 3、2 节创建虚拟环境、安装依赖、设置 `DASHSCOPE_API_KEY`。
4. 先跑 `python xrd_vl.py .\examples --dry-run` 和 `python xy_peaks.py .\examples\TiO2_anatase.xy --plot`，确认环境正常后再处理自己的图。

自己的 XRD 图和 `.xy` 数据可以另放一个文件夹，例如 `D:\xrd_qwen\my_data\`，再执行：

```powershell
python xrd_vl.py D:\xrd_qwen\my_data --data D:\xrd_qwen\my_data --context "在这里写样品信息"
```

## 9. 简单排错

| 现象 | 可能原因与处理 |
| --- | --- |
| 描线全零、叠图看起来贴上了但 2θ 偏约 2°，或把放大图描进主谱 |
| 新版本会屏蔽不同 2θ 范围的 inset、把刻度吸附到印刷短线并做峰位自检；请看 `digitize/*/trace_meta.json` 里的 flags。复核若仍为 pass 但 `.xy` 全零，属于旧结果，请加 `--overwrite` 重跑。 |
| 堆叠/多色图缺一条、近色粘连，或把 PDF 卡片竖线描成方波 | 先按图例颜色分通道描线。若仍缺最底下一条或把竖线描进谱，请看校验叠加图和 `trace_meta.json`，必要时加 `--overwrite` 用当前版本重跑。 |
| 低角主峰读成刻度值（例如 11° 峰读成 10°），或孤立彩色尖峰被抹掉 | 新版本会用轴下印刷数字重定标，并保留孤立彩色峰芯；请看 `trace_meta.json` 的 flags 是否出现「用轴下印刷数字重定标」。必要时 `--overwrite` 重跑。 |
| 提示未检测到 `DASHSCOPE_API_KEY` | 当前窗口还没有该变量。若刚用 `setx`，请关掉终端重开；或在本窗口再用 `$env:DASHSCOPE_API_KEY = "..."` 设一次。 |
| 模型不存在 / 不支持 | 该型号可能已下线或未开通。到模型广场确认后，换 `--model qwen3.8-flash`、`qwen3.6-flash` 或 `qwen3-vl-plus` 等实测可用型号。 |
| 429 / 限流 | 脚本会自动重试。仍失败就降低 `--workers`，过几分钟再跑。 |
| JSON 解析失败 | 对应的 `results/<图片完整文件名>.json` 里会保存原始文本，可打开查看；也可 `--overwrite` 重跑。 |
| Excel 打开 CSV 乱码 | 使用 Excel 打开 UTF-8 BOM 文件，或在「自文本/CSV」里选 UTF-8。 |
| `Activate.ps1` 被禁止 | 见第 3 节，对当前用户设置 `RemoteSigned`。 |
| `--fit` 提示未找到 dara-xrd | 尚未建立单独的 `dara-venv`，或未设置 `XRD_DARA_PYTHON`。按第 4.1 节安装；不要把 `dara-xrd` 装进本工具 `.venv`。 |
| DARA 报 BGMN 找不到 | 第一次拟合应自动下载。也可先运行 `dara-venv` 里的 `download_bgmn()`。Linux 一般可直接跑官方二进制。 |
